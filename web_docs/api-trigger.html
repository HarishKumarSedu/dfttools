TRIGGER & TIME

Detect voltage/current edge transitions, measure timing parameters, and analyze signal properties. All time values in seconds.

TRIGGERVTRIG_HL(signal, reference, threshold, expected_value, ...) → float

High-to-Low — fires when signal voltage drops below threshold. Callback key: 'voltage_trigger_hl'. Returns voltage at trigger point.

ParameterTypeDescription
signalstrSignal to monitor
referencestrReference node
thresholdfloatVoltage (V) — signal must fall below this
expected_valuefloatSimulation return value
Returns → float — voltage at trigger point
UVLO_L2H_Trim — sweep PVDD, detect UVLO trip @ 2.25V
LH_Th = 2.25; force_voltage = 2.0
while force_voltage <= 2.5:
    pvdd = VFORCE("PVDD", "GND", force_voltage, LH_Th*0.1)
    # IODATA0 = UVLO comparator output via digital test mux
    trigger = VTRIG_HL("IODATA0", "GND",
                        threshold=LH_Th, expected_value=pvdd)
    if trigger: break
    elif pvdd >= 2.5: break
    force_voltage += 0.025; sleep(0.001)
TRIGGERVTRIG_LH(signal, reference, threshold, expected_value, ...) → float

Low-to-High — fires when signal rises above threshold. Callback key: 'voltage_trigger_lh'. Used in OCP_LS_Trim and OCP_HS_Trim to detect comparator trip.

Returns → float — voltage at trigger point
OCP_LS_Trim — sweep codes, watch IODATA0

TIME Time Measurement APIs

All return seconds. Simulation: expected_value + random.uniform(-error_spread, error_spread).

TIMERISE_TIME_MEASURE / FALL_TIME_MEASURE(...) → float

10%→90% rise time or 90%→10% fall time. Callbacks: 'rise_time_measure', 'fall_time_measure'.

Returns → float — seconds
TIMEPOSITIVE_PULSE_WIDTH_MEASURE / NEGATIVE_PULSE_WIDTH_MEASURE(...) → float

Duration of HIGH or LOW pulse. Callbacks: 'positive_pulse_width_measure', 'negative_pulse_width_measure'.

Returns → float — seconds
Class-D SW node
t_neg = NEGATIVE_PULSE_WIDTH_MEASURE("SW","GND", expected_value=1e-6)
print(f"Neg pulse: {t_neg*1e9:.1f} ns")
TIMEPOSITIVE_DUTY_CYCLE_MEASURE / NEGATIVE_DUTY_CYCLE_MEASURE(...) → float

Duty cycle as fraction 0.0–1.0. Callbacks: 'positive_duty_cycle_measure', 'negative_duty_cycle_measure'.

Returns → float — 0.0 to 1.0
TIMETIME_DELAY_MEASURE / TIME_PERIOD_MEASURE(...) → float

TIME_DELAY_MEASURE: propagation delay between events. TIME_PERIOD_MEASURE: full period of periodic signal.

Returns → float — seconds
shutdown delay
t = TIME_DELAY_MEASURE("SDWN","GNDB", expected_value=1e-3)
print(f"Shutdown delay: {t*1e3:.3f} ms")
