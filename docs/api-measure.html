MEASURE APIs

Read electrical quantities from DUT pins. All functions support simulation — no hardware required. Pass float('inf') as expected_value to open/disconnect a measurement path.

MEASUREVMEASURE(signal, reference, expected_value, error_spread=0.0, ...) → float

Measure DC voltage. Callback key: 'voltage_measure'. Simulation: expected_value + random.uniform(-error_spread, error_spread).

ParameterTypeRequiredDescription
signalstrrequiredSignal pin: "VCC", "IODATA1", "OUTP"
referencestrrequiredReference: "GND" or another signal for differential e.g. "ADDR"
expected_valuefloatrequiredNominal in Volts. Use float('inf') to open instrument path.
error_spreadfloatoptionalUniform noise amplitude ±. Default 0.0
Returns → float — Volts
examples
# Basic (simulation → returns 3.3 ± 0.05 V)
vcc = VMEASURE("VCC", "GND", expected_value=3.3, error_spread=0.05)

# Differential: VIS 1.5V reference, IODATA1 vs ADDR, ±5mV
vref = VMEASURE(signal=IODATA1, reference=ADDR,
                expected_value=1.5, error_spread=0.005)
if abs(vref-1.5) <= 0.005: print("PASS ±5mV")

# Bandgap measurement with noise (BG_1V2_Trim)
measured = VMEASURE("IODATA1", "GND",
                     expected_value=1.188+i*7.57e-3,
                     error_spread=0.025) - buffer_offset

# Open measurement path (disconnect instrument)
VMEASURE("IODATA1", "GND", expected_value=float('Inf'))

# Class-D offset before/after cal
v1 = VMEASURE(OUTP, OUTN, 0, 0)
print(f"OUTP-OUTN offset: {v1:.4f} V")
MEASUREAMEASURE(signal, reference, expected_value, error_spread=0.0, ...) → float

Measure DC current in Amperes. Callback key: 'current_measure'. On Keysight 34401A sets FUNCtion "CURRent:DC" auto-range. Pass float('inf') to open ammeter path.

Returns → float — Amperes
VIS current tests
# VIS_1uA: 1µA at IODATA1, ±0.1µA limit
imeas = AMEASURE(IODATA1, GND, expected_value=1.0e-6, error_spread=0.1e-6)
print(f"{imeas*1e6:.3f} µA")
if abs(imeas-1e-6) <= 0.1e-6: print("PASS")

# Open ammeter path
AMEASURE(IODATA1, GND, expected_value=float('Inf'))

# Startup_REF: check BCLK present via supply current
if AMEASURE("VCC", "GND", 10e-3) < 10e-3:
    print('BCLK not reaching IC!')

MEASUREFREQMEASURE(signal='CLK', reference='GND', expected_value, error_spread=0.0, ...) → float

Measure signal frequency in Hz. Callback key: 'frequency_measure'. Core API for PLL (12.288 MHz), FLL (289.275 kHz), GPADC settle-time (4.761 MHz), VIS strobe delay (4.2 MHz).

Returns → float — Hz
PLL_Freerun_Trim
target = 12.288e6
for i in range(4):  # 2-bit VCO control field
    I2C_WRITE(DEVICEADDR, pll_vco_ctrl, i)
    f = FREQMEASURE("IODATA1", "GND",
                    expected_value=target, error_spread=target*0.1)
    err = abs(f-target)/target
    if err < min_err: min_err,best=err,hex(i)
    sleep(0.3)
