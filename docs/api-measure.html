API Reference

Measure Instructions

Measurement functions for voltage, current, resistance, and frequency. All functions support simulation mode via expected_value and error_spread parameters.

✅
Simulation Fallback

When no hardware callback is registered, VMEASURE returns expected_value + random.uniform(-error_spread, error_spread), enabling realistic test development without hardware.

VMEASURE — Voltage Measurement

VMEASURE MEAS voltage 
VMEASURE(signal: str = 'VCC', reference: str = 'GND',
         expected_value: float = 0.0, error_spread: float = 0.0) → float

Parameters

  • signal — Net/pin to measure (e.g., "A5V", "VOUT")
  • reference — Reference net, usually "GND"
  • expected_value — Simulation fallback value; also your nominal target
  • error_spread — Max random noise added in simulation (±mV range)

Example

# Measure 5V rail — nominal 4.8V ± 100mV tolerance
a5v = VMEASURE(signal="A5V", reference="GND",
               expected_value=4.8, error_spread=0.05)

if 4.7 <= a5v <= 4.9:
    print(f"PASS: {a5v:.4f}V")
else:
    print(f"FAIL: {a5v:.4f}V")

# Measure 1.5V reference
vref = VMEASURE(signal="IODATA1", reference="ADDR",
                expected_value=1.5, error_spread=0.005)
print(f"VREF = {vref:.5f}V")

AMEASURE — Current Measurement

AMEASURE MEAS current 
AMEASURE(signal: str = 'VCC', reference: str = 'GND',
         expected_value: float = 0.0, error_spread: float = 0.0) → float

Example

# Measure quiescent current on VDD
iq = AMEASURE(signal="VDD", reference="GND",
              expected_value=0.002, error_spread=0.0005)
print(f"IQ = {iq*1000:.2f}mA")

RESMEASURE — Resistance Measurement

RESMEASURE MEAS resistance 
RESMEASURE(signal: str = 'VCC', reference: str = 'GND',
           expected_value: float = 0.0, error_spread: float = 0.0) → float

Example

r_sense = RESMEASURE(signal="RSENSE", reference="GND",
                     expected_value=10.0, error_spread=0.1)
print(f"R_SENSE = {r_sense:.2f}Ω")

FREQMEASURE — Frequency Measurement

FREQMEASURE MEAS frequency 
FREQMEASURE(signal: str = 'CLK', reference: str = 'GND',
            expected_value: float = 0.0, error_spread: float = 0.0) → float

Example

# Measure PLL output frequency (expected: 3.072 MHz)
f_pll = FREQMEASURE(signal="IOCLK0", reference="GND",
                    expected_value=3.072e6, error_spread=1000)
print(f"PLL freq = {f_pll/1e6:.4f} MHz")

Full Callback Example

from dfttools import *
import pyvisa

rm = pyvisa.ResourceManager()
dmm = rm.open_resource('USB0::0x2A8D::0x1401::MY57229870::INSTR')

def voltage_measure_callback(signal: str, reference: str):
    """Return (hardware_available, voltage) tuple."""
    try:
        dmm.write('MEAS:VOLT:DC?')
        voltage = float(dmm.read())
        return True, voltage
    except Exception:
        return False, None

def current_measure_callback(signal: str, reference: str):
    try:
        dmm.write('MEAS:CURR:DC?')
        current = float(dmm.read())
        return True, current
    except Exception:
        return False, None

g.hardware_callbacks['voltage_measure'] = voltage_measure_callback
g.hardware_callbacks['current_measure'] = current_measure_callback
