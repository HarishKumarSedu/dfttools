TRIM UVLO_L2H_Trim

TRIMUVLO_L2H_TrimTested

Sweeps PVDD 2V→2.5V in 25mV steps. Thermometer code order: 18→0, then 31→19 (5-bit). Monitors IODATA0 (UVLO comparator via digital test mux) with VTRIG_HL. Trip target: 2.25V.

UVLO_L2H_Trim
decimal_list = list(range(18,-1,-1)) + list(range(31,18,-1))
for Code in decimal_list:
    I2C_WRITE(DEVICEADDR, otp_ds_ref_pvdd_uvlo_trm, hex(Code))
    force_v = 2.0
    while force_v <= 2.5:
        pvdd = VFORCE("PVDD","GND", force_v, 2.25*0.1)
        trig = VTRIG_HL("IODATA0","GND", threshold=2.25, expected_value=pvdd)
        if trig: break
        elif pvdd >= 2.5: break
        force_v += 0.025; sleep(0.001)
    err = abs(pvdd-2.25)/2.25*100
    if err < min_err: min_err,best,best_val=err,hex(Code),pvdd
VFORCE("PVDD","GND",3.7)  # restore nominal
