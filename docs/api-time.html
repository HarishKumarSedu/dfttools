API Reference

Time Measurements

Timing characterization functions for measuring rise/fall time, pulse width, duty cycle, period, and delay. Essential for validating digital signal integrity and timing margins.

Complete Time API Reference

FunctionUnitDescription
RISE_TIME_MEASUREsecondsDuration for signal to transition from low to high (typically 10%→90%)
FALL_TIME_MEASUREsecondsDuration for signal to transition from high to low (90%→10%)
POSITIVE_PULSE_WIDTH_MEASUREsecondsWidth of positive (high) pulse
NEGATIVE_PULSE_WIDTH_MEASUREsecondsWidth of negative (low) pulse
POSITIVE_DUTY_CYCLE_MEASURE% (float)Ratio of positive pulse width to total period ×100
NEGATIVE_DUTY_CYCLE_MEASURE% (float)Ratio of negative pulse width to total period ×100
TIME_PERIOD_MEASUREsecondsFull period of the signal waveform
TIME_DELAY_MEASUREsecondsDelay between two signal events

Function Signatures

All time measurement functions share the same parameter pattern:

RISE_TIME_MEASURE(signal: str = 'VCC', reference: str = 'GND',
                  expected_value: float = 0.0, error_spread: float = 0.0) → float

FALL_TIME_MEASURE(signal: str = 'VCC', reference: str = 'GND',
                  expected_value: float = 0.0, error_spread: float = 0.0) → float

POSITIVE_PULSE_WIDTH_MEASURE(signal: str = 'VCC', reference: str = 'GND',
                              expected_value: float = 0.0, error_spread: float = 0.0) → float

NEGATIVE_PULSE_WIDTH_MEASURE(signal: str = 'VCC', reference: str = 'GND',
                              expected_value: float = 0.0, error_spread: float = 0.0) → float

POSITIVE_DUTY_CYCLE_MEASURE (signal, reference, expected_value, error_spread) → float  # returns %
NEGATIVE_DUTY_CYCLE_MEASURE (signal, reference, expected_value, error_spread) → float  # returns %

TIME_PERIOD_MEASURE(signal: str = 'VCC', reference: str = 'GND',
                    expected_value: float = 0.0, error_spread: float = 0.0) → float

TIME_DELAY_MEASURE (signal: str = 'VCC', reference: str = 'GND',
                    expected_value: float = 0.0, error_spread: float = 0.0) → float

Usage Examples

Rise and Fall Time

from dfttools import *

# Measure RESET signal edge times
t_rise = RISE_TIME_MEASURE(signal="RESETB", reference="GND",
                           expected_value=10e-9, error_spread=1e-9)
t_fall = FALL_TIME_MEASURE(signal="RESETB", reference="GND",
                           expected_value=10e-9, error_spread=1e-9)

print(f"Rise time: {t_rise*1e9:.1f}ns")
print(f"Fall time: {t_fall*1e9:.1f}ns")

Pulse Width and Duty Cycle

# Verify clock duty cycle
clk_period  = TIME_PERIOD_MEASURE(signal="IOCLK0", reference="GND",
                                   expected_value=3.257e-7)  # ~325.5ns = 3.072MHz
duty_pos    = POSITIVE_DUTY_CYCLE_MEASURE(signal="IOCLK0", reference="GND",
                                            expected_value=50.0, error_spread=1.0)
pw_positive = POSITIVE_PULSE_WIDTH_MEASURE(signal="IOCLK0", reference="GND",
                                             expected_value=1.628e-7)

print(f"Period:     {clk_period*1e9:.1f}ns ({1/clk_period/1e6:.3f}MHz)")
print(f"Duty cycle: {duty_pos:.1f}%")
print(f"+PW:        {pw_positive*1e9:.1f}ns")

if 48.0 < duty_pos < 52.0:
    print("PASS: Duty cycle within ±2%")
else:
    print(f"FAIL: Duty cycle {duty_pos:.1f}% out of range")

Time Delay Between Events

# Measure delay between TRIGGER and OUTPUT response
t_delay = TIME_DELAY_MEASURE(signal="VOUT", reference="TRIGGER",
                              expected_value=500e-9, error_spread=10e-9)
print(f"Propagation delay: {t_delay*1e9:.0f}ns")

if t_delay < 600e-9:
    print("PASS: Delay under 600ns")
else:
    print(f"FAIL: Delay {t_delay*1e9:.0f}ns exceeds 600ns limit")

Time Measurement Callbacks

from dfttools import *

def rise_time_callback(signal: str, reference: str):
    # Query scope for rise time
    scope.write(":MEAS:RIS? CH1")
    t_rise = float(scope.read())
    return True, t_rise

def fall_time_callback(signal: str, reference: str):
    scope.write(":MEAS:FALL? CH1")
    t_fall = float(scope.read())
    return True, t_fall

def period_callback(signal: str, reference: str):
    scope.write(":MEAS:PER? CH1")
    period = float(scope.read())
    return True, period

def duty_cycle_callback(signal: str, reference: str):
    scope.write(":MEAS:DUTY? CH1")
    duty = float(scope.read())
    return True, duty

g.hardware_callbacks['rise_time_measure']            = rise_time_callback
g.hardware_callbacks['fall_time_measure']            = fall_time_callback
g.hardware_callbacks['time_period_measure']          = period_callback
g.hardware_callbacks['positive_duty_cycle_measure']  = duty_cycle_callback
✅
All measurements are hardware-agnostic

Use any oscilloscope or timing analyzer that supports SCPI commands. Replace the scope commands above with your instrument's specific query strings.
