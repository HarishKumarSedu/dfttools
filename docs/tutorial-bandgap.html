Bandgap Reference Trimming

A complete end-to-end test program: sweep a 4-bit trim code over all 16 values, measure the resulting bandgap voltage at each step, and select the optimal code that minimizes error from a target of 1.242V.

🎯
What this tutorial covers

I2C page switching, test register unlocking, trim code sweep, VMEASURE with error tracking, pass/fail limit checking, and writing the optimal trim code back to OTP.

Test Overview

The bandgap reference in most mixed-signal ICs has a process-variation offset that must be corrected by writing a 4-bit trim code to an OTP register. The procedure:

  1. Configure the chip: unlock I2C pages, enable analog test MUX, route bandgap to test pin
  2. Sweep all 16 trim codes (0x0 through 0xF)
  3. Measure the bandgap voltage at each code with a multimeter
  4. Select the code producing the closest voltage to 1.242V
  5. Validate the optimal voltage is within ±10% of target
  6. Write the optimal code (or 0 on failure) back to the trim register

Complete Test Program

from dfttools import *
from time import sleep
from PyMCP2221A import PyMCP2221A
from multimeter import mul_34401A

Test_Name = 'Trim_BG'
print(f'............ {Test_Name} ........')

# ─ Step 1: Configure device ─────────────────────────────────────
# Select page 0
I2C_WRITE(device_address=0x68, field_info=i2c_page_sel, write_value=0x0)
# Unlock I2C
I2C_WRITE(device_address=0x68, field_info=i2c_unlock, write_value=0x1)
# Disable clock monitor
I2C_WRITE(device_address=0x68, field_info=tdm_fsyn_rate_mnt_en, write_value=0x1)
# Unlock test registers (two-step sequence)
I2C_WRITE(device_address=0x68, field_info=unlock_tst_addr, write_value=0xaa)
I2C_WRITE(device_address=0x68, field_info=unlock_tst_addr, write_value=0xbb)
# Switch to page 1 for OTP access
I2C_WRITE(device_address=0x68, field_info=i2c_page_sel, write_value=0x1)
# Clear OTP burnt flag to allow writes
I2C_WRITE(device_address=0x68, field_info=otp_burnt_b, write_value=0x0)
# Enable analog test MUX
I2C_WRITE(device_address=0x68, field_info=amux2_en, write_value=0x1)
# Enable reference test mode
I2C_WRITE(device_address=0x68, field_info=ref_test_en, write_value=0x1)
# Select bandgap output on analog test bus (sel=6 → bandgap)
I2C_WRITE(device_address=0x68, field_info=ana_test_sel, write_value=0x6)

# ─ Step 2: Define trim parameters ──────────────────────────────
percentage    = 0.10      # ±10% acceptance window
typical_value = 1.242    # Target bandgap voltage (V)
low_value     = typical_value * (1 - percentage)  # 1.1178V
high_value    = typical_value * (1 + percentage)  # 1.3662V
step_size     = 0.077625 # Voltage step per trim code (V)
num_steps     = 2**4     # 4-bit trim → 16 codes
noise_std_dev = 0.025    # Measurement noise (simulation)

min_error         = float('inf')
optimal_code      = None
optimal_measured  = None

# ─ Step 3: Sweep all trim codes ────────────────────────────────
for i in range(num_steps):
    # Write trim code i to OTP register 0xC1[7:4]
    I2C_WRITE(device_address=0x68, field_info=ref_vbg_trim,
              write_value=hex(i))

    # Expected voltage rises linearly with trim code
    expected = low_value + i * step_size

    # Measure bandgap at HWMute test pin
    measured = VMEASURE(signal="HWMute", reference="GND",
                         expected_value=expected, error_spread=noise_std_dev)

    error = abs(measured - typical_value) / abs(typical_value) * 100
    print(f"  Code {hex(i)}: {measured:.7f}V  error={error:.4f}%")

    if error < min_error:
        min_error = error
        optimal_code = hex(i)
        optimal_measured = measured

    sleep(0.1)  # Settling time between steps

# ─ Step 4: Validate and program ────────────────────────────────
if low_value < optimal_measured < high_value:
    print(f'............ {Test_Name} Passed ........')
    I2C_WRITE(device_address=0x68, field_info=ref_vbg_trim,
              write_value=optimal_code)
else:
    print(f'............ {Test_Name} Failed ........')
    I2C_WRITE(device_address=0x68, field_info=ref_vbg_trim,
              write_value=0)  # Safe default on failure

print(f"Optimal Code:  {optimal_code}")
print(f"Optimal Value: {optimal_measured:.7f}V  (Target: {typical_value}V)")
print(f"Minimum Error: {min_error:.7f}%")

Hardware Callback Setup

To run against real hardware, register these callbacks before the test:

from PyMCP2221A import PyMCP2221A
from multimeter import mul_34401A

def custom_i2c_write_callback(device_address, register_address, value, register):
    mcp = PyMCP2221A.PyMCP2221A()
    mcp.I2C_Init()
    default = int(register['Default'], 16)
    mask    = int(register['Mask'],    16)
    lsb     = register['POS']
    byte    = ((default & ~mask) | (value << lsb)) & 0xFF
    mcp.I2C_Write(device_address, bytearray([register_address, byte]))
    return True

def custom_voltage_measure_callback(signal, reference):
    multimeter = mul_34401A('USB0::0x2A8D::0x1401::MY57229870::INSTR')
    voltage = multimeter.meas_V()
    if voltage is not None:
        return True, voltage
    return False, None

g.hardware_callbacks = {
    'i2c_write':      custom_i2c_write_callback,
    'voltage_measure': custom_voltage_measure_callback,
}

Field Info Definitions Used

i2c_unlock0x00[0]PAG0Unlock I2C write access
unlock_tst_addr0xF7[7:0]PAG0Two-step test unlock (0xAA then 0xBB)
otp_burnt_b0x40[7]PAG1Clear to allow OTP writes
amux2_en0x20[1]PAG1Enable analog test MUX2
ref_test_en0x1E[5]PAG1Enable reference test mode

ref_vbg_trim0xC1[7:4]PAG14-bit bandgap trim code

Key Design Points

  • Two-step unlock: Writing 0xAA then 0xBB to the same register unlocks test registers. Order matters.
  • Page switching: Most DUT configurations live on page 0; OTP trim registers are on page 1. Always use i2c_page_sel to switch.
  • Simulation mode: Remove the hardware callbacks and the test runs entirely in simulation — expected values trend linearly with trim code, noise is added by error_spread.
  • Safe default: On failure, always write 0 to the trim register as a safe, known default.
