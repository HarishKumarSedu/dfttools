Trigger Instructions

Trigger functions detect voltage and current threshold crossings — high-to-low, low-to-high, and level-good — enabling conditional test flows based on real-time hardware state.

Voltage Triggers

VTRIG_HL TRIGGER H→L

Triggers when the signal voltage crosses a threshold from High to Low.

VTRIG_HL(signal: str = 'VCC', reference: str = 'GND',
         threshold: float = 0.0) → bool
  • signal — Signal to monitor
  • reference — Reference node
  • threshold — Voltage threshold value in volts

Returns: True if the signal dropped below threshold, False otherwise.

# Check if VDD fell below 1.62V (10% undervoltage)
fell = VTRIG_HL(signal="VDD", reference="GND", threshold=1.62)
if fell:
    print("ALERT: VDD dropped below 1.62V")
VTRIG_LH TRIGGER L→H

Triggers when the signal voltage crosses a threshold from Low to High.

VTRIG_LH(signal: str = 'VCC', reference: str = 'GND',
         threshold: float = 0.0) → bool
# Wait for PGOOD to go HIGH above 1.0V
pgood_ok = VTRIG_LH(signal="PGOOD", reference="GND", threshold=1.0)
if pgood_ok:
    print("PASS: PGOOD asserted")
else:
    print("FAIL: PGOOD did not assert")
VTRIG_LG TRIGGER Level Good

Triggers when signal is within acceptable range (Level Good / within spec).

VTRIG_LG(signal: str = 'VCC', reference: str = 'GND',
         threshold: float = 0.0) → bool
# Check signal is at a valid low level (< 0.05V)
is_low = VTRIG_LG(signal="IOCLK0", reference="GND", threshold=0.05)
print(f"Level-good check: {is_low}")

Trigger Callbacks

from dfttools import *
import random

def vtrig_hl_callback(g, signal: str, reference: str, threshold: float):
    """Return (hardware_available, triggered_bool)"""
    # Example: read current voltage, check if below threshold
    measured_voltage = float(dmm.query("MEAS:VOLT:DC?"))
    triggered = measured_voltage < threshold
    return True, triggered

def vtrig_lh_callback(g, signal: str, reference: str, threshold: float):
    measured_voltage = float(dmm.query("MEAS:VOLT:DC?"))
    triggered = measured_voltage > threshold
    return True, triggered

def atrig_hl_callback(g, signal: str, reference: str, threshold: float):
    measured_current = float(dmm.query("MEAS:CURR:DC?"))
    triggered = measured_current < threshold
    return True, triggered

g.hardware_callbacks['voltage_trigger_hl'] = vtrig_hl_callback
g.hardware_callbacks['voltage_trigger_lh'] = vtrig_lh_callback
g.hardware_callbacks['current_trigger_hl'] = atrig_hl_callback

Using Triggers in Test Flow

from dfttools import *
from time import sleep

# Power up sequence with trigger-based verification
VFORCE(signal="PVDD", reference="GND", value=3.7)
sleep(0.1)

# Verify PGOOD asserted after powerup
pgood = VTRIG_LH(signal="PGOOD", reference="GND", threshold=1.0)
if not pgood:
    print("FAIL: PGOOD did not assert after powerup")
    VFORCE(signal="PVDD", reference="GND", value=0.0)  # Power off
    raise RuntimeError("Startup failed")

# Continue test after confirming power state
print("PASS: Power good asserted — continuing test")
vout = VMEASURE(signal="VOUT", reference="GND", expected_value=5.0)
print(f"VOUT = {vout:.4f}V")
