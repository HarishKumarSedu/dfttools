Startup Procedure

The startup procedure is the foundation of almost every test. It powers on the DUT, initializes I2C communication, unlocks test registers, and configures basic chip settings. Understanding it is essential for writing any test.

What Startup Does

The startup procedure performs three categories of actions in order:

  1. Force supply rails — Apply VDD (1.8V), RESETB (1.8V), and PVDD (3.7V) via VFORCE calls
  2. Initialize I2C — Select page 0, configure PLL mode and lock detect counter
  3. Unlock test registers — Switch to page 1, write the two-step unlock sequence (0xAA then 0xBB to register 0x2F), then return to page 0

Full Startup Code

from time import sleep
from dfttools import *

def startup():
    Test_Name = 'Startup'
    print(f'............ {Test_Name} ........')

    # ── 1. Force supply rails ──────────────────────────────────────
    VFORCE(signal=VDD,    reference=GND, value=1.8)
    VFORCE(signal=RESETB, reference=GND, value=1.8)
    VFORCE(signal=PVDD,   reference=GND, value=3.7)
    sleep(0.2)  # Allow rails to settle (200ms)

    # ── 2. Initialize page 0 registers ───────────────────────────
    I2C_WRITE(device_address=DEVICEADDR, field_info=i2c_page_sel,    write_value=0x0)
    I2C_WRITE(device_address=DEVICEADDR, field_info=pll_mode,        write_value=0x2)
    I2C_WRITE(device_address=DEVICEADDR, field_info=pll_ldet_cnt,    write_value=0x10)

    # ── 3. Unlock test registers (page 1) ───────────────────────
    I2C_REG_WRITE(device_address=DEVICEADDR, register_address=0xFE,
                  write_value=0x01, PageNo=1)  # Switch to page 1
    I2C_REG_WRITE(device_address=DEVICEADDR, register_address=0x2F,
                  write_value=0xAA, PageNo=1)  # Unlock step 1
    I2C_REG_WRITE(device_address=DEVICEADDR, register_address=0x2F,
                  write_value=0xBB, PageNo=1)  # Unlock step 2

    # ── 4. Return to page 0 and configure signal conditioning ───
    I2C_WRITE(device_address=DEVICEADDR, field_info=i2c_page_sel,    write_value=0x0)
    I2C_WRITE(device_address=DEVICEADDR, field_info=tdm_fsyn_mnt_mode, write_value=0x0)
    I2C_WRITE(device_address=DEVICEADDR, field_info=iopad0_hyst,     write_value=0x1)
    I2C_WRITE(device_address=DEVICEADDR, field_info=iodata1_hyst,    write_value=0x1)
    I2C_WRITE(device_address=DEVICEADDR, field_info=ioclk1_hyst,     write_value=0x1)
    I2C_WRITE(device_address=DEVICEADDR, field_info=ioclk2_hyst,     write_value=0x1)

    # Read and log calibration measurement code
    cal_meas_code = I2C_READ(device_address=DEVICEADDR,
                              field_info=cal_meas, expected_value=0x0)
    print(f"  cal_meas = {hex(cal_meas_code)}")

    I2C_WRITE(device_address=DEVICEADDR, field_info=prechg_step_time, write_value=0x2)

if __name__ == '__main__':
    startup()

Register Explanations

Register FieldValuePurpose
i2c_page_sel (0xFE)0x0Select page 0 — normal operating registers
pll_mode0x2Configure PLL operating mode
pll_ldet_cnt0x10PLL lock detect counter threshold
0x2F (unlock)0xAA → 0xBBTwo-step sequence to unlock test register page
tdm_fsyn_mnt_mode0x0TDM frame sync monitor mode
iopad0_hyst0x1Enable Schmitt trigger hysteresis on IOPAD0
iodata1_hyst0x1Enable Schmitt trigger hysteresis on IODATA1
ioclk1_hyst / ioclk2_hyst0x1Enable hysteresis on clock pins
cal_measREADRead calibration code — log for traceability
prechg_step_time0x2Pre-charge step timing configuration

Startup 5.2V Variant

A variant startup for testing at 5.2V PVDD is structurally identical but uses a higher PVDD value:

def startup_5v2():
    VFORCE(signal=VDD,    reference=GND, value=1.8)
    VFORCE(signal=RESETB, reference=GND, value=1.8)
    VFORCE(signal=PVDD,   reference=GND, value=5.2)  # Higher supply
    sleep(0.2)
    # ... same I2C init sequence ...

Common Usage Pattern

Every test imports and calls startup first. Here is a minimal test skeleton:

from dfttools import *
from Procedures.Startup import startup

def my_test():
    # 1. Power up DUT
    startup()

    # 2. Configure test-specific settings
    I2C_WRITE(...)

    # 3. Measure
    result = VMEASURE(...)

    # 4. Evaluate
    if LOW < result < HIGH:
        print("PASS")
    else:
        print("FAIL")

if __name__ == '__main__':
    my_test()
⚠️
Always run startup before any test

Without startup, the DUT has no power supply and I2C registers are uninitialized. Calling any I2C_WRITE before startup will either fail silently (simulation) or cause hardware communication errors.
