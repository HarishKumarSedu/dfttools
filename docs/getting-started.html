02 Quick Start

quickstart.py
from dfttools import *   # all APIs + g, db, detect_and_handle_main_db
from time import sleep

# ── Simulation mode (no hardware needed) ──────────────────
VFORCE(signal="VCC", reference="GND", value=3.3)

vcc = VMEASURE(signal="VCC", reference="GND",
               expected_value=3.3, error_spread=0.05)
print(f"VCC = {vcc:.4f} V")

I2C_WRITE(device_address=0x68,
          field_info={'fieldname':'i2c_unlock','length':1,
                      'registers':[{'REG':'0x00','POS':0,'Mask':'0x1',
                                     'Length':1,'FieldMSB':0,
                                     'FieldLSB':0,'Default':'00'}]},
          write_value=0x1)

print(db.dump())  # see all logged calls
SIMULATION MODE — All APIs work without hardware. Measure functions return expected_value + random.uniform(-error_spread, error_spread). I²C write/read return False/expected_value silently when no callback is registered.

03 Architecture

Every instruction follows the same 4-step dispatch:

STEP 1
Look up callback key in g.hardware_callbacks
STEP 2
If None → run simulation (return expected ± noise)
STEP 3
If registered → call hardware driver, get real value
STEP 4
Append result to g.output and log record to db

05 Hardware Callbacks

measure callback signature
def my_dmm_measure(signal: str, reference: str,
                   expected_value: float, *args, **kwargs):
    """Returns (hardware_available: bool, measured_value: float)"""
    from multimeter import mul_34401A
    dmm = mul_34401A("USB0::0x2A8D::0x1401::MY57229870::INSTR")
    v = dmm.meas_V()
    return (True, v) if v else (False, None)

g.hardware_callbacks['voltage_measure'] = my_dmm_measure
I²C field-level write callback (PyMCP2221A)
def my_i2c_write(device_address: int, register_address: int,
                  value: int, register: dict) -> bool:
    """register = one entry from field_info['registers']"""
    from PyMCP2221A import PyMCP2221A
    mcp = PyMCP2221A.PyMCP2221A(); mcp.I2C_Init()
    default = int(register['Default'], 16)
    mask    = int(register['Mask'],    16)
    data    = ((default & mask) | value << register['POS']) & 0xFF
    mcp.I2C_Write(device_address, bytearray([register_address, data]))
    return True

g.hardware_callbacks['i2c_write'] = my_i2c_write

06 NestedDB — db

Auto-logs every instruction call. UUID-keyed, reverse-indexed for fast filtered queries.

MethodReturnsDescription
db.create(data)strUUID of new record
db.find(criteria)list[dict]Matching records (includes _id)
db.find_filtered(criteria)list[dict]Without _id/_created
db.find_last_record(criteria)dict|NoneMost recent match
db.dump()list[dict]All records without _id/_created
db.count(criteria)intRecord count
db.clear()NoneWipe all records
db usage
from dfttools.glob import db, detect_and_handle_main_db
detect_and_handle_main_db()     # clears db when running as __main__

# Filter I²C operations only
i2c_ops = db.find_filtered({'Instruction': 'I2C'})

# Export for CI pipeline
import json
with open('results.json', 'w') as f:
    json.dump(db.dump(), f, indent=2)

07 Simulation Mode

MEASURE (no callback)
Returns expected_value + random.uniform(-error_spread, error_spread)
FORCE (no callback)
Returns value + random.uniform(-error_spread, error_spread)
I2C_WRITE (no callback)
Returns False silently — write not executed
I2C_READ (no callback)
Returns expected_value — useful for sweep logic testing
