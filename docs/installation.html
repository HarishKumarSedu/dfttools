Getting Started

Installation

Install dfttools directly from GitHub. The library requires Python 3.8 or later and a handful of standard dependencies.

Install from GitHub

The recommended installation method is directly from the official GitHub repository:

pip uninstall -y dfttools
pip install git+https://github.com/HarishkumarSedu/dfttools.git@main
⚠️
Always reinstall fresh

Uninstall any existing version first to ensure you get the latest API with all callback and instruction updates.

Install from Source (Development)

If you are contributing to dfttools or need to modify the library:

git clone https://github.com/HarishkumarSedu/dfttools.git
cd dfttools
pip install -e .       # editable install — changes take effect immediately

Dependencies

DFTtools has minimal dependencies, all installable via pip:

PackageVersionPurpose
python-box>=7.0Attribute-style dict access for instruction codes
pyvisa>=1.12VISA instrument communication (optional — for real hardware)
PyMCP2221AlatestUSB-to-I2C bridge (optional — for I2C hardware)
pyserial>=3.5Serial communication (optional — for serial instruments)
✅
No hardware required for development

DFTtools runs fully in simulation mode when no hardware callbacks are registered. Install only the core library to start writing and testing test programs.

Verify Installation

from dfttools import *

# Should print the value (simulation mode — no hardware needed)
result = VMEASURE(signal="VCC", reference="GND", expected_value=3.3, error_spread=0.01)
print(f"Simulated measurement: {result:.4f}V")  # e.g. 3.3041V

Environment Setup for Real Hardware

If you plan to use real ATE hardware, install the appropriate driver libraries:

# For VISA instruments (multimeters, power supplies, oscilloscopes)
pip install pyvisa pyvisa-py

# For MCP2221A USB-I2C bridge
pip install PyMCP2221A

# For serial instruments
pip install pyserial
💡
VISA Backend

pyvisa-py provides a pure-Python VISA backend that works without a National Instruments or Keysight VISA installation. For full VISA support, install NI-VISA or Keysight IO Libraries Suite.
