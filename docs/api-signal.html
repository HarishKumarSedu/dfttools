Signal Measurements

Advanced waveform measurement functions for characterizing signal quality — phase, amplitude, RMS, peak-to-peak, spectrum, pulse counts, and edge detection. All functions support simulation mode.

💡
Common Pattern

All signal measurement functions share the same parameter pattern: (signal, reference, expected_value, error_spread). They return the measured value or expected_value ± error_spread in simulation mode.

Amplitude Measurements

SIGNAL_PEAK_TO_PEAK_MEASURE SIGNAL

Measures the peak-to-peak voltage swing of a waveform.

SIGNAL_PEAK_TO_PEAK_MEASURE(signal='VCC', reference='GND',
                             expected_value=0.0, error_spread=0.0) → float
vpp = SIGNAL_PEAK_TO_PEAK_MEASURE(signal="OUT+", reference="GND",
                                    expected_value=3.2, error_spread=0.05)
print(f"Vpp = {vpp:.4f}V")
SIGNAL_RMS_MEASURE SIGNAL

Measures the Root Mean Square (RMS) voltage of the signal.

SIGNAL_RMS_MEASURE(signal='VCC', reference='GND',
                   expected_value=0.0, error_spread=0.0) → float
vrms = SIGNAL_RMS_MEASURE(signal="OUT+", reference="GND",
                           expected_value=2.26, error_spread=0.02)
print(f"Vrms = {vrms:.4f}V")
SIGNAL_AMPLITUDE_MEASURE SIGNAL

Measures signal amplitude (peak relative to base level).

SIGNAL_AMPLITUDE_MEASURE(signal='VCC', reference='GND',
                         expected_value=0.0, error_spread=0.0) → float
SIGNAL_MEAN_MEASURE SIGNAL

Measures the mean (DC average) of the signal over a measurement window.

SIGNAL_MEAN_MEASURE(signal='VCC', reference='GND',
                    expected_value=0.0, error_spread=0.0) → float

Level Measurements

FunctionReturnsDescription
SIGNAL_MIN_MEASUREfloat (V)Minimum voltage level during measurement window
SIGNAL_MAX_MEASUREfloat (V)Maximum voltage level during measurement window
SIGNAL_HIGH_MEASUREfloat (V)High-level voltage (logic HIGH representative level)
SIGNAL_LOW_MEASUREfloat (V)Low-level voltage (logic LOW representative level)
 
# Check digital signal levels
v_high = SIGNAL_HIGH_MEASURE(signal="IOCLK0", reference="GND",
                              expected_value=1.8, error_spread=0.05)
v_low  = SIGNAL_LOW_MEASURE (signal="IOCLK0", reference="GND",
                              expected_value=0.0, error_spread=0.02)
v_min  = SIGNAL_MIN_MEASURE (signal="IOCLK0", reference="GND",
                              expected_value=0.0, error_spread=0.01)
v_max  = SIGNAL_MAX_MEASURE (signal="IOCLK0", reference="GND",
                              expected_value=1.8, error_spread=0.05)

print(f"VOH={v_high:.3f}V  VOL={v_low:.3f}V")
print(f"Vmin={v_min:.3f}V  Vmax={v_max:.3f}V")

Phase Measurement

SIGNAL_PHASE_MEASURE SIGNAL

Measures the phase difference between signal and reference (in degrees or radians, depending on your callback).

SIGNAL_PHASE_MEASURE(signal='VCC', reference='GND',
                     expected_value=0.0, error_spread=0.0) → float
phase = SIGNAL_PHASE_MEASURE(signal="OUT+", reference="CLK",
                              expected_value=45.0, error_spread=1.0)
print(f"Phase = {phase:.2f}°")

Spectrum Measurement

SIGNAL_SPECTRUM_MEASURE SIGNAL

Returns a frequency spectrum representation. The return type depends on your callback implementation — typically a dict or array of frequency bins.

SIGNAL_SPECTRUM_MEASURE(signal='VCC', reference='GND',
                        expected_value=None, error_spread=0.0) → dict | list
⚠️
Complex return type

In simulation mode, expected_value is returned as-is (no noise added) since noise addition is not meaningful for spectrum data structures.

Pulse & Edge Count Measurements

FunctionReturnsDescription
SIGNAL_POSITIVE_PULSE_COUNT_MEASUREintCount of positive pulses on the signal
SIGNAL_NEGATIVE_PULSE_COUNT_MEASUREintCount of negative pulses on the signal
SIGNAL_RAISING_EDGE_COUNT_MEASUREintCount of rising (low→high) edges
SIGNAL_FALLING_EDGE_COUNT_MEASUREintCount of falling (high→low) edges
 
# Verify startup pulse sequence
rising_edges = SIGNAL_RAISING_EDGE_COUNT_MEASURE(signal="RESETB", reference="GND",
                                                    expected_value=1)
if rising_edges == 1:
    print("PASS: Reset released once")
else:
    print(f"FAIL: Expected 1 rising edge, got {rising_edges}")

Signal Measurement Callbacks

Register callbacks under the keys matching each measurement type:

def signal_rms_callback(signal: str, reference: str):
    # Query oscilloscope for RMS measurement
    scope.write(f":MEAS:RMS? CH1")
    rms = float(scope.read())
    return True, rms

def signal_phase_callback(signal: str, reference: str):
    scope.write(":MEAS:PHAS? CH1,CH2")
    phase = float(scope.read())
    return True, phase

g.hardware_callbacks['signal_rms_measure']   = signal_rms_callback
g.hardware_callbacks['signal_phase_measure'] = signal_phase_callback
