API Reference

I2C Instructions

Field-level I2C read and write operations with full bitmask support, multi-register fields, and read-only attribute protection. Uses detailed JSON register metadata from your device register map.

I2C_WRITE

I2C_WRITE I2C write

Write a value to an I2C register field using detailed field metadata. Supports multi-register fields and respects read-only attributes.

I2C_WRITE(device_address: int, field_info: dict, write_value: int) → bool

Parameters

  • device_address — 7-bit I2C device address (e.g., 0x68)
  • field_info — Register field metadata dictionary (from your register map JSON)
  • write_value — Integer value to write to the field

Returns

True if write succeeded, False if no hardware callback is registered or write fails.

Example

from dfttools import *

# Field info dict — normally auto-generated from register map
i2c_page_sel = {
    "fieldname": "i2c_page_sel",
    "length": 1,
    "registers": [{
        "REG": "0xFE", "POS": 0,
        "RegisterName": "Page selection",
        "RegisterLength": 8,
        "Name": "i2c_page_sel",
        "Mask": "0x1", "Length": 1,
        "FieldMSB": 0, "FieldLSB": 0,
        "Attribute": "0000000N",
        "Default": "00", "User": "000000YY",
        "Clocking": "SMB", "Reset": "C",
        "PageName": "PAG0"
    }]
}

# Select page 0
I2C_WRITE(device_address=0x68, field_info=i2c_page_sel, write_value=0x0)

# Select page 1
I2C_WRITE(device_address=0x68, field_info=i2c_page_sel, write_value=0x1)

I2C_READ

I2C_READ I2C read

Read a value from an I2C register field. Combines multi-register fields and applies bitmasks automatically.

I2C_READ(device_address: int, field_info: dict, expected_value: int) → int

Parameters

  • device_address — 7-bit I2C device address
  • field_info — Register field metadata dictionary
  • expected_value — Default value returned if no hardware callback is registered

Example

# Read a 10-bit ADC result from two registers
vbat_meas = {
    "fieldname": "vbat_meas", "length": 10,
    "registers": [
        {"REG": "0x31", "Mask": "0x3",  "Length": 2,
         "FieldMSB": 9, "FieldLSB": 8, "Attribute": "000000RR"},
        {"REG": "0x32", "Mask": "0xFF", "Length": 8,
         "FieldMSB": 7, "FieldLSB": 0, "Attribute": "RRRRRRRR"}
    ]
}

result = I2C_READ(device_address=0x68, field_info=vbat_meas, expected_value=0)
print(f"VBAT code: {result}")

I2C_REG_WRITE — Raw Register Write

I2C_REG_WRITE I2C raw

Write a raw byte value directly to a register address. Used for unlock sequences and page switching that require exact byte values.

I2C_REG_WRITE(device_address: int, register_address: int, write_value: int, PageNo: int = 0) → bool

Example

# Switch to page 1
I2C_REG_WRITE(device_address=DEVICEADDR, register_address=0xFE,
              write_value=0x01, PageNo=1)

# Unlock test page (two-step sequence)
I2C_REG_WRITE(device_address=DEVICEADDR, register_address=0x2F,
              write_value=0xAA, PageNo=1)
I2C_REG_WRITE(device_address=DEVICEADDR, register_address=0x2F,
              write_value=0xBB, PageNo=1)

Field Info Dictionary Reference

The field_info dict is the core of the I2C instruction system. It describes how a named register field maps to physical device registers:

field_info = {
    "fieldname": "example_field",   # Human-readable field name
    "length": 4,                      # Total bit length of the field
    "registers": [                     # One entry per physical register
        {
            "REG": "0xC1",             # Register address (hex string)
            "POS": 4,                  # Bit position within register
            "RegisterName": "OTP reg 129",
            "RegisterLength": 8,        # Always 8 for byte-wide registers
            "Name": "example_field[3:0]",
            "Mask": "0xF0",            # Bitmask for this field's bits
            "Length": 4,               # Number of bits in this register
            "FieldMSB": 3,             # MSB bit index
            "FieldLSB": 0,             # LSB bit index
            "Attribute": "NNNNNNNN",  # N=normal, R=read-only
            "Default": "00",           # Reset default value
            "User": "00000000",        # User-writeable bits mask
            "Clocking": "FRO",         # Clock domain
            "Reset": "C",              # Reset type
            "PageName": "PAG1"         # Register page
        }
    ]
}

Read-Only Register Protection

When the Attribute field contains RR, the register is read-only. I2C_WRITE automatically skips such registers:

# This field has read-only bits (RR in Attribute)
ro_field = {
    "fieldname": "vbat_meas", "length": 8,
    "registers": [{
        "REG": "0x32", "Attribute": "RRRRRRRR",  # all read-only
        ...
    }]
}

# I2C_WRITE will print a warning and return False
success = I2C_WRITE(device_address=0x68, field_info=ro_field, write_value=0xFF)
# "Register vbat_meas is read-only. Skipping write operation."
# success = False

I2C Callbacks

from dfttools import *
from PyMCP2221A import PyMCP2221A

def i2c_write_callback(device_address: int, register_address: int,
                        value: int, register: dict):
    """
    Called for each register in a multi-register field.
    'register' is the single register entry from field_info['registers'].
    """
    mcp = PyMCP2221A.PyMCP2221A()
    mcp.I2C_Init()
    default = int(register['Default'], 16)
    mask    = int(register['Mask'],    16)
    lsb     = register['POS']
    byte_val = ((default & ~mask) | (value << lsb)) & 0xFF
    mcp.I2C_Write(device_address, bytearray([register_address, byte_val]))
    return True

def i2c_read_callback(device_address: int, register_address: int) → int:
    mcp = PyMCP2221A.PyMCP2221A()
    mcp.I2C_Init()
    data = mcp.I2C_Read(device_address, 1)
    return data[0]

g.hardware_callbacks['i2c_write'] = i2c_write_callback
g.hardware_callbacks['i2c_read']  = i2c_read_callback
⚠️
Unlock Sequences

Many test registers require an unlock sequence before access. Always use I2C_REG_WRITE with the exact byte values (e.g., 0xAA then 0xBB) for unlock registers, as field-level masking may change the byte value.
