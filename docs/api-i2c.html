I²CI2C_WRITE(device_address, field_info, write_value) → bool

Write a named register field. Auto handles bit masking, shifting, multi-register fields. Callback key: 'i2c_write'.

ParameterTypeRequiredDescription
device_addressint|strrequired7-bit I²C address: 0x68 or "0x68"
field_infodictrequiredField descriptor — see schema below
write_valueint|strrequiredValue: 0x1, "0xa", or decimal int
Returns → bool — True on success, False if no callback
common write patterns
# 1-bit field: unlock I²C
I2C_WRITE(device_address=0x68,
  field_info={'fieldname':'i2c_unlock','length':1,
    'registers':[{'REG':'0x00','POS':0,'Mask':'0x1',
                   'Length':1,'FieldMSB':0,'FieldLSB':0,
                   'Default':'00','PageName':'PAG0'}]},
  write_value=0x1)

# 4-bit OTP trim field (BG_1V2_Trim)
I2C_WRITE(DEVICEADDR, otp_ds_ref_bg_trm_1v2, hex(i))

# 9-bit DAC field spanning 2 registers (tst_data_dwa)
I2C_WRITE(0x38, {'fieldname':'tst_data_dwa','length':9,
  'registers':[
    {'REG':'0x11','POS':0,'Mask':'0x1', 'Length':1,
     'FieldMSB':8,'FieldLSB':8,'Default':'0x00'},
    {'REG':'0x12','POS':0,'Mask':'0xFF','Length':8,
     'FieldMSB':7,'FieldLSB':0,'Default':'0x00'}
  ]}, write_value=0xFF)  # saturate DAC OUTP
I²CI2C_READ(device_address, field_info, expected_value=0x1) → int

Read a named field. Handles unmasking/shifting. Returns expected_value in simulation. Callback key: 'i2c_read'.

Returns → int — field value
read-back examples (Trimming tests)
# GPADC temperature offset: target=674 @ 27°C
temp_read = I2C_READ(DEVICEADDR, temp_meas, expected_value=0x2BC)
temp_corr = 674 - temp_read
if temp_corr < 0: temp_corr = 256 + temp_corr

# V-sense code (16-bit signed two's complement)
vsns_raw = I2C_READ(DEVICEADDR, v_sense, expected_value=0xFFFF)
vsns_code = (0x10000-vsns_raw) if vsns_raw & 0x8000 else vsns_raw

# GPADC Vbat two-point
CODE0 = I2C_READ(DEVICEADDR, vbat_meas, 0x1FE)
CODE1 = I2C_READ(DEVICEADDR, vbat_meas, 0x380)
I²CI2C_REG_WRITE / I2C_REG_READ(device_address, register_address, value, PageNo=0)

Write/read a raw 8-bit register. Used for direct page switches and full-register operations. Callbacks: 'i2c_reg_write', 'i2c_reg_read'.

READ Returns → int — 8-bit register value
page switching + direct writes
# Page 0
I2C_REG_WRITE(DEVICEADDR, 0xFE, 0x00, PageNo=0)
# Page 1
I2C_REG_WRITE(DEVICEADDR, 0xFE, 0x01, PageNo=1)
# Class-D cal_start trigger
I2C_REG_WRITE(0x38, 0x79, 0x1, 1)
# V-sense TDM slot 0 config
I2C_REG_WRITE(DEVICEADDR, 0x44, 0xC0, PageNo=0)
I²CI2C_BIT_WRITE / I2C_BIT_READ(device_address, register_address, msb, lsb, value|expected, PageNo=0)

Bit-field access. Mask = ((1 << (msb-lsb+1))-1) << lsb. Callbacks: 'i2c_bit_write', 'i2c_bit_read'.

READ Returns → int
bit-level access
# Write bit[1:0] of reg 0x11
I2C_BIT_WRITE(0x38, 0x11, msb=1, lsb=0, write_value=2, PageNo=0)
# Set single bit 7 of reg 0x20
I2C_BIT_WRITE(0x68, 0x20, msb=7, lsb=7, write_value=1, PageNo=1)

SCHEMA field_info Dictionary

Auto-generated from regmap.json. Outer keys:

KeyTypeDescription
fieldnamestrLogical name, e.g. "i2c_unlock", "ref_vbg_trim"
lengthintTotal bit width (may span multiple registers)
registerslist[dict]One entry per physical register slice

Each registers entry:

KeyTypeDescription
REGstrRegister address hex string: "0xC1"
POSintBit position (LSB) within register byte
MaskstrBit mask: "0x0F", "0x80"
LengthintBits contributed by this slice
FieldMSB / FieldLSBintMSB/LSB within combined field value
DefaultstrPower-on default hex: "00", "80"
PageNamestr"PAG0" or "PAG1"
AttributestrPer-bit: N=Normal, Y=User-writable, R=Read-only
Clockingstr"SMB" = SMBus clock, "FRO" = internal ring osc

PATTERN Page Selection

Startup_REF.py — complete unlock + page navigation
# Step 1: Page 0, unlock I²C, enable TDM monitor
I2C_WRITE(0x68, i2c_page_sel,         write_value=0x0)
I2C_WRITE(0x68, i2c_unlock,           write_value=0x1)
I2C_WRITE(0x68, tdm_fsyn_rate_mnt_en, write_value=0x1)

# Step 2: Two-step test register unlock
I2C_WRITE(0x68, unlock_tst_addr, write_value=0xaa)
I2C_WRITE(0x68, unlock_tst_addr, write_value=0xbb)

# Step 3: Page 1 — test registers / OTP
I2C_WRITE(0x68, i2c_page_sel, write_value=0x1)
I2C_WRITE(0x68, force_pll_en, write_value=0x1)

# Step 4: Back to page 0
I2C_WRITE(0x68, i2c_page_sel, write_value=0x0)

# Alternative: I2C_REG_WRITE for raw page select
I2C_REG_WRITE(DEVICEADDR, 0xFE, 0x01, PageNo=1)
I2C_REG_WRITE(DEVICEADDR, 0xFE, 0x00, PageNo=0)
