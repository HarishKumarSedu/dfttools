Getting Started

Architecture

DFTtools is organized in four layers: the instruction interface, a hardware abstraction layer, a callback registry, and the global context. Understanding these layers explains how a single-line test call becomes a real hardware operation.

Four-Layer Model

┌──────────────────────────────────────────────────────┐
│  LAYER 1 · INSTRUCTION INTERFACE                      │
│  VFORCE, VMEASURE, I2C_WRITE, VTRIG_HL, ...           │
│  Public API — one function per operation              │
├──────────────────────────────────────────────────────┤
│  LAYER 2 · HARDWARE ABSTRACTION                       │
│  apply_force_and_measure()                            │
│  apply_i2c_read_write()                               │
│  apply_force_and_measure_sweep()                      │
│  apply_time_measure() / apply_signal_measure()        │
├──────────────────────────────────────────────────────┤
│  LAYER 3 · CALLBACK REGISTRY (g.hardware_callbacks)   │
│  User-registered Python functions for each hw type    │
│  e.g. 'voltage_force' → voltage_force_callback()      │
├──────────────────────────────────────────────────────┤
│  LAYER 4 · HARDWARE                                   │
│  Real ATE instruments: power supply, DMM,             │
│  oscilloscope, I2C bridge, electronic load...         │
└──────────────────────────────────────────────────────┘

Call Flow Example

When you call VFORCE(signal="VDD", reference="GND", value=1.8):

# Layer 1 — Public instruction
def VFORCE(signal, reference, value):
    hw_avail, measured = apply_force_and_measure(
        g, signal, reference, value, 'voltage_force')  # → Layer 2
    if not hw_avail:
        return {'signal': signal, 'reference': reference, 'value': value}
    g.output.append({'type': 'FORCE', ...})
    return measured

# Layer 2 — Hardware abstraction
def apply_force_and_measure(g, signal, reference, value, force_type):
    callback = g.hardware_callbacks.get(force_type)  # → Layer 3
    if callback:
        return callback(g, signal, reference, value)   # → Layer 4
    return False, 0  # simulation mode

# Layer 3/4 — Your hardware callback
def voltage_force_callback(g, signal, reference, value):
    psu.write(f"OUTP:VOLT {value}")  # Real hardware command
    actual = float(psu.query("MEAS:VOLT?"))
    return True, actual

Simulation Mode

The library has a built-in simulation mode. When no callback is registered, every instruction falls back gracefully:

InstructionSimulation behavior
VFORCE / AFORCE / ...Returns a dict: {'signal': ..., 'reference': ..., 'value': ...}
VMEASURE / AMEASURE / ...Returns expected_value + random.uniform(-error_spread, error_spread)
I2C_WRITEReturns False (no-op)
I2C_READReturns expected_value
VTRIG_HL / VTRIG_LHReturns False (not triggered)
