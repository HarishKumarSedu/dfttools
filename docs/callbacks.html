Core Concepts

Callbacks

Callbacks are the bridge between dfttools' abstract instruction layer and your real ATE hardware. By registering callback functions, you connect VFORCE, VMEASURE, I2C_WRITE and all other instructions to physical instruments.

💡
Simulation vs Hardware Mode

When no callback is registered for an instruction, it runs in simulation mode — returning expected values with optional noise. Register callbacks only for the hardware you have physically connected.

Callback Signatures

There are two callback families with different signatures:

Force Callbacks — return (hardware_available, applied_value)

def voltage_force_callback(g, signal: str, reference: str, value: float):
    # g = global context (access g.output, g.hardware_callbacks, etc.)
    # Apply voltage to hardware...
    return True, value  # (hardware_exists: bool, actual_value: float)

def current_force_callback(g, signal, reference, value):
    return True, value

def resistance_force_callback(g, signal, reference, value):
    return True, value

def frequency_force_callback(g, signal, reference, value):
    return True, value

Measure Callbacks — return (hardware_available, measured_value)

def voltage_measure_callback(signal: str, reference: str):
    # Note: NO 'g' parameter for measure callbacks
    voltage = 3.3012   # Read from instrument
    return True, voltage

def current_measure_callback(signal: str, reference: str):
    return True, 0.002  # 2mA

I2C Callbacks

def i2c_write_callback(device_address: int, register_address: int,
                        value: int, register: dict) → bool:
    # register is the single register entry from field_info['registers']
    return True  # success

def i2c_read_callback(device_address: int, register_address: int) → int:
    return 0xFF  # raw byte read from register

Registering Callbacks

Register all callbacks by assigning to g.hardware_callbacks:

from dfttools import *

# Register callbacks as a dict update
g.hardware_callbacks.update({
    'voltage_force':    voltage_force_callback,
    'current_force':    current_force_callback,
    'voltage_measure':  voltage_measure_callback,
    'i2c_write':        i2c_write_callback,
    'i2c_read':         i2c_read_callback,
})

# Or assign individually
g.hardware_callbacks['voltage_force'] = voltage_force_callback

Complete Hardware Setup Example — VISA Instruments

from dfttools import *
import pyvisa
from PyMCP2221A import PyMCP2221A

# ─ Open instruments ─────────────────────────────────────────────
rm  = pyvisa.ResourceManager()
psu = rm.open_resource('USB0::0x0957::0x0807::MY49012345::INSTR')
dmm = rm.open_resource('USB0::0x2A8D::0x1401::MY57229870::INSTR')

# ─ Force callbacks ──────────────────────────────────────────────
def v_force(g, signal, reference, value):
    psu.write(f"OUTP:VOLT {value}")
    psu.write("OUTP ON")
    actual = float(psu.query("MEAS:VOLT?"))
    return True, actual

# ─ Measure callbacks ────────────────────────────────────────────
def v_measure(signal, reference):
    try:
        v = float(dmm.query("MEAS:VOLT:DC?"))
        return True, v
    except:
        return False, None

# ─ I2C callbacks (MCP2221A USB bridge) ──────────────────────────
def i2c_write(dev_addr, reg_addr, value, register):
    mcp = PyMCP2221A.PyMCP2221A()
    mcp.I2C_Init()
    default = int(register['Default'], 16)
    mask    = int(register['Mask'], 16)
    lsb     = register['POS']
    byte    = ((default & ~mask) | (value << lsb)) & 0xFF
    mcp.I2C_Write(dev_addr, bytearray([reg_addr, byte]))
    return True

def i2c_read(dev_addr, reg_addr):
    mcp = PyMCP2221A.PyMCP2221A()
    mcp.I2C_Init()
    mcp.I2C_Write(dev_addr, bytearray([reg_addr]))
    data = mcp.I2C_Read(dev_addr, 1)
    return data[0]

# ─ Register all callbacks ───────────────────────────────────────
g.hardware_callbacks = {
    'voltage_force':   v_force,
    'voltage_measure': v_measure,
    'i2c_write':       i2c_write,
    'i2c_read':        i2c_read,
}
