Force Instructions

Force instructions apply a specific value (voltage, current, resistance, or frequency) to a hardware signal. They are hardware-agnostic and delegate to registered callbacks in g.hardware_callbacks.

💡
Simulation Mode

If no callback is registered for a force type, the function returns a dict {'signal': ..., 'reference': ..., 'value': ...} and nothing is applied to hardware.

VFORCE — Voltage Force

VFORCE FORCE voltage

Apply a voltage to a signal pin relative to a reference. Uses the 'voltage_force' callback.

VFORCE(signal: str = 'VCC', reference: str = 'GND', value: float = 0.0) → float | dict

Parameters

  • signal — Pin/net name to force voltage on (e.g., "VDD", "PVDD")
  • reference — Reference node, typically "GND"
  • value — Voltage in volts (float)

Returns

The actual applied voltage (float) from the callback, or a dict if no hardware is connected.

Example

from dfttools import *

# Force 1.8V on VDD rail
VFORCE(signal="VDD", reference="GND", value=1.8)

# Force 3.7V on PVDD
VFORCE(signal="PVDD", reference="GND", value=3.7)

Callback Signature

def voltage_force_callback(g, signal: str, reference: str, value: float):
    # Apply voltage using your hardware API
    psu.write(f"VOLT {value}")
    actual = float(psu.query("VOLT?"))
    return True, actual  # (hardware_exists, actual_value)

g.hardware_callbacks['voltage_force'] = voltage_force_callback

AFORCE — Current Force

AFORCE FORCE current

Force a current value on a signal. Uses the 'current_force' callback. Typical use: setting load current on an electronic load.

AFORCE(signal: str = 'VCC', reference: str = 'GND', value: float = 0.0) → float | dict

Example

# Force 1.0A load on output channel
AFORCE(signal="OUT+", reference="GND", value=1.0)

Callback Signature

def current_force_callback(g, signal, reference, value):
    eload.write(f"CURR {value}")
    actual = float(eload.query("CURR?"))
    return True, actual

g.hardware_callbacks['current_force'] = current_force_callback

RESFORCE — Resistance Force

RESFORCE FORCE resistance

Force a resistance value. Used with programmable resistors or electronic loads in resistance mode.

RESFORCE(signal: str = 'VCC', reference: str = 'GND', value: float = 0.0) → float | dict

Example

# Set 1000 Ohm load
RESFORCE(signal="OUT", reference="GND", value=1000.0)

FREQFORCE — Frequency Force

FREQFORCE FORCE frequency

Force a clock or signal frequency. Used with function generators or programmable oscillators.

FREQFORCE(signal: str = 'CLK', reference: str = 'GND', value: float = 0.0) → float | dict

Example

# Set 3.072 MHz clock on IOCLK0
FREQFORCE(signal="IOCLK0", reference="GND", value=3.072e6)

Complete Hardware Callback Setup

from dfttools import *

def voltage_force_callback(g, signal, reference, value):
    print(f"[PSU] Setting {signal} = {value}V")
    return True, value

def current_force_callback(g, signal, reference, value):
    print(f"[ELOAD] Setting {signal} = {value}A")
    return True, value

def resistance_force_callback(g, signal, reference, value):
    print(f"[ELOAD] Resistance mode {signal} = {value}Ω")
    return True, value

def frequency_force_callback(g, signal, reference, value):
    print(f"[FG] Setting {signal} = {value}Hz")
    return True, value

g.hardware_callbacks = {
    'voltage_force':    voltage_force_callback,
    'current_force':    current_force_callback,
    'resistance_force': resistance_force_callback,
    'frequency_force':  frequency_force_callback,
}

How Force Instructions Work Internally

All force functions call the internal apply_force_and_measure() dispatch function:

def apply_force_and_measure(g, signal, reference, value, force_type):
    if g.hardware_callbacks[force_type]:
        hw_available, measured = g.hardware_callbacks[force_type](
            g, signal, reference, value)
        if hw_available:
            return hw_available, measured
        return False, 0
    return False, 0   # No callback → simulation mode
