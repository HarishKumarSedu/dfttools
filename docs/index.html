What is DFTtools?

DFTtools is a Python library developed by Inventvm for writing automated semiconductor test programs. It provides a high-level "pseudo-Python" language for describing test operations (force, measure, I2C read/write, sweep, trigger) that is hardware-agnostic — real hardware is connected via callback functions.

The companion tool DFTide (Inventvm's test IDE) reads .json test program files and compiles them into executable Python test programs using the dfttools API. Designers write test programs in the pseudo-Python format; DFTide handles execution and hardware interfacing.

Key Features

⚡

Force Instructions

Apply voltage, current, resistance, or frequency to any signal with VFORCE, AFORCE, RESFORCE, FREQFORCE.
📊

Measure Instructions

Measure voltage, current, resistance, and frequency with hardware fallback simulation for development.
🔗

I2C Read / Write

Field-level register access with bitmask support, multi-register fields, and read-only protection.
📈

Force Sweep

Sweep voltage or current from start to end value with configurable step size and step timing.
🔌

Callback System

Hardware-agnostic design. Register your own callbacks for any instrument — VISA, serial, proprietary APIs.
🛠️

DFTide IDE

Inventvm's integrated test development environment that reads JSON and compiles executable test programs.

Quick Example

from dfttools import *
from time import sleep

# Force power supply rails
VFORCE(signal="VDD", reference="GND", value=1.8)
VFORCE(signal="PVDD", reference="GND", value=3.7)
sleep(0.2)  # Wait for rails to settle

# Write an I2C register field
I2C_WRITE(device_address=0x68, field_info=i2c_page_sel, write_value=0x0)

# Measure output voltage
vout = VMEASURE(signal="A5V", reference="GND",
                expected_value=4.8, error_spread=0.05)

if 4.7 < vout < 4.9:
    print(f"PASS: {vout:.4f}V within spec")
else:
    print(f"FAIL: {vout:.4f}V out of range")
💡
Simulation Mode

When no hardware callback is registered, dfttools automatically returns expected_value ± error_spread, allowing complete test development without any physical hardware.
